# Зависимости

Правило: перед добавлением любой зависимости — проверить лицензию, размер, наличие сетевых вызовов; вписать сюда. Runtime-зависимости только вендореные (`vendor/`), `dependencies = []` в pyproject.

## Вендореные (runtime)

| Пакет | Версия | Лицензия | Размер | Сетевые вызовы | Назначение |
|---|---|---|---|---|---|
| PyYAML (`vendor/yaml`) | 6.0.3 | MIT | ~600 КБ (pure-python, без C-расширения) | нет (проверено grep по `socket/urllib/http`) | чтение `config/perimeter.yaml`, mapping-файлов 1С |
| colibri (`vendor/colibri`) | 1.1.1 | Apache-2.0 | ~1 МБ исходников C+Python | нет в рантайме (C-код — ноль сетевых символов; setup-скрипты загрузки весов исключены из вендоринга) | inference-движок GLM-5.2 |
