---
name: counterparty-report
description: Сводный отчёт по контрагенту — реквизиты, документы, взаиморасчёты
---

Порядок:
1. get_counterparty — реквизиты (название, ИНН) и key.
2. find_document по каждому уместному типу за период (по умолчанию — текущий квартал).
3. ledger_report — сальдо взаиморасчётов.
4. Ответ: краткая шапка (контрагент, ИНН), список документов «№ … от …», итоговое сальдо. Без воды.
